# 買い物電卓

商品の値段と個数を入力し、買い物の合計金額を計算するシンプルなWebアプリです。

https://grkaym.github.io/shopping-calc/

## 機能

- 商品価格と個数の追加
- 同じ商品の「価格 × 個数」計算
- 入力した商品の一覧表示
- 合計金額と商品点数の自動計算
- 商品ごとの削除
- 入力内容の一括削除
- スマートフォン対応

## 使い方

1. `index.html` をブラウザで開きます。
2. 予算を入力して「買い物を始める」を押します。
3. 商品の値段と個数を入力して「追加」を押します。
4. 入力した商品の合計金額と残額が自動で更新されます。

## 使用技術

- HTML
- CSS
- Vanilla JavaScript

ビルドや依存パッケージのインストールは不要です。
